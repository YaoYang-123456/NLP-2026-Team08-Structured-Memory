## 代表性错误与限度

- 明信片累计25张：B0错误相减成8，B1/B2候选最终答25。已保存检索事实明确包含旧17和新25，主要是证据利用/统计区间错误。单次探索不能把差异完全归因于规则。
- 自种食材晚餐：三组均没有利用rubric中的樱桃番茄/罗勒/薄荷，围绕检索出的调酒信息推荐菜单。提示词检索内容以调酒、聚会等为主，是检索不足的明确线索；不据此声称完整历史不存在食材信息。
- 本科课程海报大学：把其他会议/研究背景套到本科课程，存在事件混淆；直接猜Harvard为No，承认缺信息又猜测的回答为uncertain。
- Sapiens剩余页数：三组均指出某些信息缺失又作假设估计，原拒答标准对这类混合回答没有明确处理，保留uncertain。这是本轮候选无法选择的共同原因，不靠改成No或Yes补齐覆盖。
- 观鸟时长：B1答三个月、参考两个月，原时间rubric明确允许days/weeks/months的off-by-one，因此判Yes，同时标记没有正确扣除一个月的推理缺陷；基准接受不代表推理无误。
- 首饰数量：三组给两件而参考三件；已检索信息中有项链、耳环及大量无关内容。没有完整证据审计来确定缺失项或计数口径，具体原因保留未知，不能武断只归因于规则。

下一步最值得做的是请人明确“承认信息不足后继续猜测”的拒答判分政策，并作为新版本协议另行验证；不要事后改写本轮标签来选出候选。本轮不追加实验。
