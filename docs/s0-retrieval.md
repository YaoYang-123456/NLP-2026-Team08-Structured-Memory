# B：S0 普通检索基线——运行及交接

负责人：`YaoYang-123456`；任务 [#24](https://github.com/YaoYang-123456/NLP-2026-Team08-Structured-Memory/issues/24)。本实现仅承担**检索**，不训练模型，不进行回答生成或评分。当前本地测试仅使用构造数据和假嵌入器；它们不算 LoCoMo 真实实验。

## 方案与输入

读取 [LoCoMo 官方数据](https://github.com/snap-research/locomo) `data/locomo10.json`，对选中会话逐 `session_N` 提取原始对话中的 `dia_id`、`speaker`、`text` 和 `session_N_date_time`；如原对话含图片和 BLIP 描述，描述会以 `[image caption generated by BLIP]` 标识。保留会话的原始先后顺序，长文本按字符长度切块。每块有稳定来源 ID：`sample_id:session_N:dia_id:分块序号`。

**仅允许使用 `conversation` 构建语料。** 不从 `qa.answer`、`qa.evidence`、`observation`、`session_summary` 或 `event_summary` 生成检索上下文。原题 `question` 用来编码查询，但回答标签不会作为检索数据输入。

A（[#26](https://github.com/YaoYang-123456/NLP-2026-Team08-Structured-Memory/issues/26)）冻结开发样本后，另存一份 UTF-8 的 `questions.jsonl`，每行**仅**四个字段（类型要严格一致）：

```json
{"sample_id":"example-conversation","qa_index":4,"question":"What is the cat called?","category":1}
```

`qa_index` 是原会话 `qa` 数组的零起始下标，过滤题型后不能重新编号。此文件只用于传入 A 已冻结的问题，不由 B 独立选择 5/30 题。**此四字段文件是 B 与 A 的待确认交接格式，若 A 已提供不同的正式格式，先对齐且保留原 ID，不修改冻结清单。**

## 向量检索

使用本机 [Ollama](https://github.com/ollama/ollama) 的 `/api/embed`（仅允许回环地址），模型名称由 A 确认；不自动下载权重。对检索块和问题使用**同一个**嵌入模型，向量 L2 归一化后计算余弦相似度，降序选取 `top_k=60`，平分时保持语料原始顺序。会话块只需编码一次；无标签的嵌入缓存放在 Git 忽略的 `output/s0-embeddings/` 下，键由模型名与具体块文本计算。换模型权重即使标签名不变，也应清理缓存或新建缓存目录。

分块默认 480 字符是初步实现参数，并非 StructMem 论文中公布的平铺事实基线。LoCoMo 原始对话向量检索（S0）不能称作原论文的“flat fact memory”消融；检索模型、块大小、实际维度、Ollama 版本须在正式实验记录中明确。

## 运行命令（A 与 F 交付以后）

先确认 A 的冻结题单及本地嵌入模型确实可用，然后在仓库根目录运行。**以下是待运行命令，不是完成记录**：

```sh
python scripts/run_s0.py \
  --conversations data/locomo/locomo10.json \
  --selection data/locomo/smoke5.questions.jsonl \
  --embedding-model bge-m3 \
  --out output/s0-smoke5
```

这里的 `bge-m3` 和路径只是示例，最终以 A 选定且已安装的模型和文件为准。先跑 A 的固定 5 题，再用同一版本改传 30 题清单及一个**新**输出目录。拒绝覆盖已有输出；若接口不匹配或模型不可用，停止并记录实际错误，不替换题目或偷偷回退 BM25。

输出：

- `s0.inputs.jsonl`：每行恰好 `sample_id`、`qa_index`、`question`、`category`、`contexts`；每个上下文恰好 `source_ids`、`kind=raw`、`text`。可直接供 F 的 `run_qa.py --method S0` 读取，来源和时间在文本中保留。
- `s0.retrieval.jsonl`：独立记录每题的 `rank`、余弦得分、来源 IDs 和实际语料块总数，不掺入模型提示词。
- `s0.manifest.json`：原始数据/题单 SHA-256、模型名、参数、题数等；`accuracy=null`，`answer_generation_calls=0`。

与 F [统一回答接口（PR #35）](https://github.com/YaoYang-123456/NLP-2026-Team08-Structured-Memory/pull/35) 对接时，把上述检索输入交给其 `scripts/run_qa.py --method S0`。F 负责 API 请求、保存预测和 `usage`，E（[#31](https://github.com/YaoYang-123456/NLP-2026-Team08-Structured-Memory/issues/31)）据 `(method, sample_id, qa_index)` 评分；B 不重复开发调用客户端或评分器。F 尚未合并时请从 PR 分支检出，或等接口经集中审核合并。

## 已验证与待完成

在构造的多会话 LoCoMo 片段和假向量上，运行 `python -m unittest discover -s tests -p test_flat_rag.py -v` 检查顺序、来源、答标隔离、top-k 排序、缓存和拒绝覆盖。**离线检查与模拟嵌入均不是5题或30题的真实检索成绩。**
