1. 核对最新 main、#26、相邻任务；记录已有准备及本机实际环境。
2. 编写 scripts/prepare_locomo.py、configs/locomo-smoke.json；测试固定清单、会话隔离、问答输入字段白名单、损坏来源拒绝及重复生成一致性。
3. 在官方真实数据上冻结 30/5 题；保留完整开发会话，独立输出标签；核验消息引用与输出哈希。
4. 编写 scripts/check_locomo_environment.py，验证实际嵌入模型、维度与加载设备；无法下载时留下具体失败而不冒称通过。
5. 交付 docs/locomo-data-environment.md、reports/locomo-a-verification.json 和本人两页进展，创建关联 #26 的实现 PR。共享输入格式按仓库约定交一位相关成员审核；独立成员复验未发生时保持待验收。

网络限制：shell 直连 GitHub 失败时通过已连接 GitHub 工具读取固定版本，发布分支以最新 main 为基线；不将本地旧 main 或他人未跟踪笔记打包提交。
