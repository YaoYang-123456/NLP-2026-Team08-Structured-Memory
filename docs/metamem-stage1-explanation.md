# MetaMem 第一阶段：论文对应与十分钟中文讲解

本文供杨垚个人学习、讲解和阶段研究使用。当前工作是 **BM25 RAG＋元记忆的小规模试点**，不是 LightMem 主实验完整复现，也不是第8队已经确定的最终方案。本文区分三个阶段：外部AI v1真实训练与验证、严格拒答v2对旧回答的离线重判，以及采用v2评分政策的三轮新生成诊断。当前结果不支持稳定增益，下一步优先诊断证据覆盖。

测试边界：历史工程验证包含`--mock test`流程，其模拟分数不是模型成绩。本轮文档核对、v1真实训练/验证、v2离线分析和三轮新生成诊断没有读取或运行真实测试；不能将这一边界扩大为“整个项目从未处理过测试文件”。

## 一、论文、代码和本地实现怎样对应

原文：[本地 PDF](../papers/structured-memory-group2/05_MetaMem.pdf)，[ACL 页面](https://aclanthology.org/2026.findings-acl.270/)。下列 p. 指 **PDF 文件页码**，p.1 为印刷页5473，p.11为5483。此次直接提取并核对了 pp.3–5、11 的方法、公式和实验设置。上游代码固定在 [66232c1](https://github.com/OpenBMB/MetaMem/tree/66232c1cb33d3d7939d323b431f21c741785142e)，不是随时变化的最新分支。

上述“符号优化”指对可读规则做离散编辑，不是梯度下降或微调权重。它仍使用带参考答案的训练数据，也消耗生成、反思、提案、合并和评分成本。标签不进入回答提示词，不意味着整个方法没有监督。

### 三种对照回答不同的问题

- **B0：空规则。**问题、检索facts、回答模型和预算与其他组一致，测不加元记忆时的表现。
- **B1：预先固定人工规则。**检验通用人工提示在相同事实上的效果；不是学习出的规则，也不参与B2候选选择。
- **B2候选：学习规则。**初始空规则和各批检查点是候选；只有按冻结的验证政策选出后，才有正式选定的B2。本次v1没有选出，故历史报告称“B2学习候选”。后续三轮诊断中的B2仅是预先固定的v1规则对照名称，不表示完成正式选择。

三组共享相同facts，目的是尽量把比较集中在如何使用证据；它不能消除生成波动，也不能证明检索已经充分。回答没用好事实和事实根本没检索到，需要分别分析。

## 二、已有证据能支持什么

### 模型身份与评分政策

既有v1运行的本地生成模型为`qwen2.5:7b-instruct-q4_K_M`，Ollama 0.34.0，加载上下文8192；权重摘要为`845dbda0ea48ed749caafd9e6037047aa19acfcfd82e704d7ca97d631a0b697e`。它承担回答、反思、提案和合并。训练回答temperature 0.7/top-p 0.95，验证0/0.8；未设置seed，不能声称确定性。

既有外部评审可确认身份是Codex、开发指令标识GPT-6系列，**精确部署版本未知**；本文编写环境同样没有可核验的精确部署版本。不能把工具列表里的模型选项当成实际执行模型身份。外部评分是APP AI文件评审，不是论文的235B judge，不是人工金标准。组织和评分来自同一APP上下文，且见过部分案例；即使隐藏方法名和旧标签，也只能称隐藏标签复核，不能称严格独立盲评。人工验收字段仍为空。

v1使用上游题型rubric，遇到“承认信息不足后又猜测”的拒答歧义保留uncertain。uncertain不算错，也不进入混合正误反思组。v2新增本项目严格拒答政策：不可回答题中，对所问事实作无依据的数值或倾向猜测判No；纯条件公式、请求补充信息可接受；其他题型沿用v1。**v2不是原论文标准**。

### v1真实训练与验证

来源：[v1执行记录](metamem-external-ai-run-20261015.md)。40个训练回答为27 Yes、8 No、5 uncertain；20题组中13组全对、3组全错、3组不确定、1组混合。只有Apex旧目标题的混合组实际贡献了规则，执行2次反思、1次提案、1次合并。后面三个检查点内容未变，不是四份独立学得的规则。

规则原文为：

> Prioritize recent memories, cross-validate facts, and understand context and chronology unless historical context is required.

可解释为：优先较近的记忆、交叉核对事实并理解背景和时间顺序，但需要历史背景时例外。这条规则并不等于“最近的信息总是正确”；“优先近期”可能干扰询问过去状态的问题，这目前只是待验证风险。

|验证配置|Yes / No / uncertain|有效覆盖|可如何解释|
|---|---|---|---|
|B0|4 / 5 / 1|9/10|4个已确认正确；不能将uncertain算成能力错误|
|B1|5 / 3 / 2|8/10|判对5个，但分母与其他组不同|
|B2非空学习候选|5 / 4 / 1|9/10|仍不满足完整覆盖，未被正式选择|

空B2候选复用同配置B0，非空候选按内容去重。所有B2候选均未达到10/10有效覆盖，历史结论为`no_full_coverage_candidate`、`selected=null`。不能改写为“选出最佳B2并提升10个百分点”。

### v2离线重判

来源：[v2敏感性分析](metamem-strict-abstention-v2-analysis.md)。在固定的70条旧回答中，12条适用严格拒答政策并重评，58条沿用v1；9条uncertain变No，3条No仍为No。没有新模型调用、重训或测试。旧规则仍是v1标签下学出的，不能称v2训练结果。

|同一批验证旧回答|B0|B1|B2学习候选|
|---|---:|---:|---:|
|v2判对 / 有效数|4/10|5/10|5/10|

覆盖率变化来自评分政策，不是模型能力改善。B2相对B0配对为：双方都对4题、仅B2对1题、仅B0对0题、双方都错5题。仅B2对的是明信片累计量：B0将累计25减去旧17得到8，B2答25。这是一个与时间/累计信息使用有关的观察，不足以证明规则的因果作用或稳定增益。

若事后将选择算法应用到v2派生评分，会选择最早非空规则`rules-01.json`；这只是敏感性分析，没有覆盖v1选择记录，没有生成正式冻结候选。不能把事后重判包装成预先采用v2协议跑完的新实验。

### 三轮新生成：没有得到稳定增益的证据

此后冻结同一10条开发验证题、检索facts、B0空规则和v1已有规则，执行三轮各20个回答，共60个新回答；本地请求61次包含预热。设置为temperature 0.7、top-p 0.95、max_tokens 1024，seed不设置，轮间交替B0/B2顺序。**这是独立的非零温度采样诊断，不与历史temperature 0的结果直接合并或解释为能力进步。** 没有新训练、反思、规则编辑或候选选择；也没有运行B1。

60条主评后，另做18条定向独立AI复核；复核前冻结“有分歧则另存uncertain”的保守处理方式，不覆盖主评。唯一分歧是第三轮Sapiens的B2回答，主评Yes、复核uncertain。定向复核不是对60条随机抽样的可靠性估计，更不是人工验收。

|轮次|B0 Yes / No / uncertain|B2 Yes / No / uncertain，保守口径|
|---|---:|---:|
|第1轮|5 / 5 / 0|5 / 5 / 0|
|第2轮|6 / 4 / 0|6 / 4 / 0|
|第3轮|6 / 4 / 0|7 / 2 / 1|
|合计|17 / 13 / 0|18 / 11 / 1|

第三轮B2的原主评为8 Yes、2 No，单独保留。保守口径为B0在30次回答中确认17对，B2确认18对并有1条不确定；**30次回答来自10题重复，不是30个独立题目**，不能据此报告稳健收益或独立泛化结论。

旧明信片优势未稳定重现：本轮三次B0为No/Yes/Yes，B2为No/No/Yes，第二轮反而只有B0对。潜在的B2独胜包括第二轮Sapiens和第三轮衣物题，但前者虽有政策允许的条件公式，也含无依据扩写；后者参考答案3涉及计数对象口径歧义。第三轮Sapiens又出现评审分歧。这些边界不足以支持“规则稳定有效”。

对10题的[证据审计](metamem-stage1-evidence.md)进一步区分了原因：晚餐关键会话、首饰题的戒指信息没有检索到，同时存在已检索证据未被正确使用的情况。新增审计证据没有回填本轮生成输入。下一方向只建议先做证据覆盖诊断，分清缺失证据与利用错误，再判断是否需要改检索或规则；当前结果不支持直接扩大模型。

本段结果依据主代理完成的本轮运行汇总及定向复核；生成设计见[冻结计划](../configs/metamem-stability-plan.json)，入口与评分、恢复方式见[复现说明](metamem-stage1-reproduce.md)。本文编写代理没有重新生成或重复独立判读60条答案。

## 三、十分钟中文讲稿

以下按内容分配时间，总计10分钟；是排练预算，不是已实测语速。讲述时展示对应表、规则原文及历史/新诊断结果表，重点留给三轮结果，不必现场运行模型。

### 0:00–1:00：为什么“记住了”仍然答错

今天介绍MetaMem，以及我做的第一阶段个人试点。先看一个例子：前三次旅行一共1800英里，第四次1200英里，第四次第一天走了300英里。问四次旅行总里程，正确答案是3000。如果把三个数字全部相加就成了3300。问题并不一定是没找到信息，而是没识别出300已经包含在1200里面。论文要解决的正是检索后怎样正确使用事实。我目前没有完整复现论文的大模型与LightMem系统，而是在较小的BM25检索和7B模型条件下，检查这条学习流程能否运行、规则是否有初步作用。

### 1:00–2:00：M与E，以及到底训练了什么

论文区分两类记忆。M保存具体事实，比如旅行的时间、地点和里程；E保存使用事实的经验，比如先判断总量与部分的包含关系，避免重复计数。普通回答把问题和M交给模型，MetaMem再加入E。这次更新的是自然语言规则，没有对模型权重做梯度训练。不过它仍然是有监督的学习：训练时需要参考答案和判分反馈，也需要多次模型调用。只有回答阶段不能看到参考；训练反思可以看到。最后评价时要固定规则，不能再利用评价题答案修改它。

### 2:00–3:30：沿Figure 2走完一次更新

现在看论文第四页Figure 2。先从空规则开始，同一道训练题随机生成多个回答，再判断每个回答对不对。随后分析每个回答成功或失败的原因，把反思汇总成规则编辑提案，例如增加一条规则、删除错误规则，或者修改旧规则。同一批不同题目的提案可能重复，也可能冲突，所以还要有一次批量合并，最后才得到下一版本规则。这个过程对应式6到式10。

这里有一个容易漏掉的代码细节：官方默认多次采样时，只对同题既有对又有错的组更新。正文没有把这一筛选明确写成条件，本地实现沿用了它，并增加全部采样有效的要求。因此，全错不等于会产生更多学习信号；在当前机制下，全错会跳过。uncertain也不能偷偷算错，否则可能人为制造混合组，让规则根据不可靠标签更新。

### 3:30–4:40：本地保留什么、换掉什么

原论文主要用LightMem组织事实，再用向量检索。我这里直接把带日期的原始消息切块，用BM25找最多20个片段，正文限制为12000字符。所以保留的是采样、判分、反思、提案、合并的元记忆学习链，替换了事实记忆底座和模型规模。训练也缩小到20题、每题两次、每批5题、只跑一轮。

三个对照分别是B0空规则、B1预先写好的人工规则、B2学习规则候选。三组的事实完全相同，便于观察规则是否改变证据使用。但这不能证明检索没有缺失，也不能把所有错误都归因于规则。规则最多8条、2048字节，这是工程预算，不是模型token数。

### 4:40–5:50：为什么需要验证，为什么这次没有选出B2

论文每折是350题训练、50题验证、100题测试，五折取平均。我这里固定10题验证，并预先规定：候选必须全部获得有效判分，才按正确数选择，同分取最早检查点，初始空规则也参加。这个完整覆盖门槛是本地政策，不是论文的明确要求。

这样做是为了避免只在容易被判分的几题上得到高比例，便声称最好。v1里B0是4对、5错、1个不确定；人工规则是5对、3错、2个不确定；学习候选是5对、4错、1个不确定。因为没有候选满足十题完整判分，所以没有正式选定B2。这里最准确的结果是“产生了一个学习候选，但当前协议无法完成选择”，不是“训练已经成功提升”。

### 5:50–7:00：实际学到了哪条规则

40个训练回答中，只有一个题组满足一对一错。它问的是Apex过去的目标；一次回答正确，一次错误。模型经过两次反思、一次提案和一次合并，形成了这条规则：优先较近记忆、交叉核对事实、理解背景和时间顺序，但历史问题例外。后面三个批次都没有改变它。

所以不能说20道题都贡献了规则，也不能把四个相同检查点算成四次独立成功。内容审查没有发现直接抄入具体训练答案，但“没有泄漏”并不代表“规则有效”。它很宽泛，优先近期还可能干扰问过去状态的问题。这种潜在冲突需要用配对案例与重复结果检验，不能凭规则听起来合理就通过。

### 7:00–7:40：v2政策与旧回答重判

v1中“先说不知道、后面又猜一个值”的拒答判法不够明确，所以保留了uncertain。后来新增v2：不可回答题如果还作无依据判断，就判No；纯条件公式可以接受。这是项目政策，不是论文标准。对旧回答离线重判后，原验证变成B0四对、B1和学习候选五对，但回答没变，不是模型变强。规则仍由v1学出，历史未选定结论也保留。

### 7:40–9:10：三轮真实诊断与不稳定的优势

接下来确实做了新生成：冻结10道开发题和两份规则，每题B0、B2各三次，共60个回答，加预热共61次本地请求。temperature是0.7、top-p是0.95，没有设置seed。这与历史零温度不同，是一项独立采样诊断；不训练、不选规则、不碰测试。

60条主评后另做18条定向独立复核，预先规定分歧另存uncertain。保守结果三轮B0分别5、6、6对，B2分别5、6、7对，最后一轮还有1条不确定。主评原先将那条判对，因此原8对2错也保留。合计是17对与18对加1条不确定，但这是10题重复，不能当30个独立样本。

旧明信片优势没有稳定重现：三次B0错、对、对，B2错、错、对，第二轮还反向。新的B2独胜也有边界：Sapiens条件公式与无依据扩写并存，衣物题参考的计数对象有歧义。这些结果不支持稳定收益。评分仍是AI，精确版本未知，定向复核也不是人工金标准。

### 9:10–10:00：阶段结论

阶段结论是：流程可以产生规则，但训练信号稀疏，三轮新诊断没有支持稳定增益。10题证据审计已经定位晚餐关键会话和戒指没有检索到，也看到已检索但没用好的信息。因此下一步优先诊断证据覆盖，分开缺失证据和利用错误，暂不扩大模型。审计找到的新证据没有回填本轮回答，这仍是个人开发验证，没有独立测试结论。是否采用为全组方案，还要结合其他成员路线和组内决策。
