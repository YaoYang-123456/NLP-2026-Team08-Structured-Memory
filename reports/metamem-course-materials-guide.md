# MetaMem 个人阅读材料使用说明

整理日期：2026-10-19。材料服务个人论文阅读与已有试点交流，原始试点负责人杨垚，整理及汇报人字段留空，供本人核对填写。

## 文件

- [Word 阅读报告](metamem-reading-and-pilot-20261019.docx)：8 页，含问题、方法、论文主结果与消融、已有试点和局限。
- [可编辑 PPT](metamem-reading-and-pilot-20261019-v2.pptx)：18 页，包含原论文方法图、4 张原生表格、3 张原生图表及逐页中文讲稿。讲稿位于备注窗格，来源同时保留在页面底部与备注。
- [报告文字源](metamem-reading-and-pilot-20261019.md)、[幻灯片内容源](metamem-course-slides.json)：便于修订与组内整合。
- [校验记录](metamem-course-materials-verification.json)：文件哈希、数值来源、页数、原生图表和实际渲染方式。

先用报告理解 M 与 E、训练反馈与测试回答的区别，再结合 PPT 备注练习讲解。论文的 Avg 与本地试点的判对次数分别报告；不能混算不同温度、评分政策和阶段的成绩。十题重复三次仍只有十道独立开发题。

## 使用前由本人完成

填写姓名和学号，确认讲解者与现有试点的贡献归属。亲自阅读原论文并核对自己能解释方法、原验证为何未选 B2、为什么引用存在不等于依据正确，以及三阶段负结果的范围。

视频尚未录制。按老师或助教后续明确的时长组织讲解，现有原始通知未规定 60 分钟。本文档和讲稿不代表已经录制或提交视频。

六篇论文的全组横向整合、成员贡献确认、最终课程验收、提交时间和渠道仍需另行完成；这两份个人材料不替代全组最终 Word/PPT。衣物、观鸟和 AI 判分分歧的人类复核没有完成，材料保留这些限制。

## 实际校验与生成

Word 使用 Python DOCX 生成，技能默认渲染器因本机缺少 LibreOffice 失败；随后通过 WPS 原生 API 导出 PDF，并用 Poppler 渲染检查全部 8 页。临时 PDF 和页面图片仅用于检查，不作为额外交付。

PPT 使用 Artifact Tool 生成。所有 18 页已渲染查看；原生表格、图表、嵌入数据工作簿、字体声明和包结构通过最终校验。柱状图纵轴从 0 开始，避免自动截断夸大差异。没有声称在 Microsoft PowerPoint 中实际打开测试。

生成源脚本为 `scripts/build_metamem_course_materials.py` 和 `scripts/build_metamem_course_slides.mjs`。使用 Codex 随附 Python 和 Node；前者生成 Word、Markdown 与幻灯片内容 JSON，后者读取 JSON 生成 PPT。PPT 构建目录需要指向运行时包目录的 `node_modules` 链接，命令的两个参数分别为演示技能目录和运行时 Python 路径。重建前保留已有文件，并选择新的最终输出及校验回执文件名；终结器不会覆盖现有输出。

本轮没有运行新的真实模型实验、读取测试答案或更改原始评分。本轮修改围绕材料整理和生成入口，未重复运行模型程序的全量测试。所有交付文件小于 20 MB；原数据、权重和完整调用日志未加入 Git。
